# Ankush Goyal — Portfolio

Built with [Astro](https://astro.build) + Tailwind CSS.

## Prerequisites

- Node.js 18+ (recommended: latest LTS)
- npm (or pnpm/yarn)

## Install

```bash
npm install
```

## Run locally

```bash
npm run dev
```

Astro will print the local URL (usually `http://localhost:4321`).

## Build

```bash
npm run build
npm run preview
```

## Customize

- Update the contact email in `src/pages/contact.astro`
- Edit projects in `src/content/projects/`
